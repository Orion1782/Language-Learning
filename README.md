# Language Learning Principles.

## Principal of Learning Language

- Immersive exposure: practical communication without being professional;
- "Fake it until make it": prioritizing real-world usage over rote memorization;
- Long-term Practice: take language learning as a means to end, utilize it for other stuff.

## What is "Language"? (Structural Linguistics Perspective)

In structural linguistics, a language is a system of signs and rules that allows members of a community to communicate meaningfully, enabling communication and the transmission of meaning within a community.
